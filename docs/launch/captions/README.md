# BRKAR demo subtitle drafts

These SRT files are timing drafts for the four Mission Lab demonstrations. Each lab has Arabic, English and French narration tracks, following the approved voice lines in [`../REELS-SCRIPT-PACK.md`](../REELS-SCRIPT-PACK.md). They are source material for recording and editing, not finished captions or videos.

Before export, record the selected adult voiceover, adjust every cue to the actual speech, and have a fluent reviewer check the wording and reading pace. Preview Arabic in the target editor to confirm right-to-left shaping, punctuation and line breaks. Keep captions within the phone-safe area with strong contrast, and review the complete video at normal playback speed. The intended duration is roughly 30–40 seconds, extending when readability requires it.

The set supports up to four demo topics in three language variants (12 caption tracks). The current launch plan still calls for four demonstrations; it does not require twelve separate exports. Use only invented preview answers, keep the product's actual results visible, and do not capture family-device or production-browser data.
